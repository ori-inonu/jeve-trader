# Jeve Trader 0.4.1 — instalação e aviso de atualizações

O aplicativo consulta releases ao abrir e apresenta um ícone de atualização no cabeçalho. Quando existe uma versão maior com instalador Windows compatível, o aviso mostra a versão e as notas e permite abrir a página da release. O download e a instalação são manuais; feche o aplicativo antes de executar o instalador.

O repositório permanece privado. A consulta reutiliza uma credencial Git autorizada já existente no Windows, sem solicitar ou armazenar a chave na interface. Falhas de acesso/rede são visíveis e não são apresentadas como “atualizado”. Não é necessário configurar a chave JEV para consultar atualizações.

O instalador mantém o identificador JevWIN, o atalho da área de trabalho e os dados em `%LOCALAPPDATA%\JevWIN`. O nome do atalho continua JevWIN para preservar a instalação existente. Requer Windows x64 e WebView2 Evergreen.

Esta versão é um painel experimental. Dados reais Profit/Excel não foram validados nesta entrega; o demo continua explícito. Ordens permanecem manuais. O termômetro direcional, a nova cadência JEV e os alertas de oportunidade estão especificados no mapa Wayfinder e ainda não foram implementados. O índice financeiro permanece em aguardar quando falta um modelo aprovado.

Validação do código: 203 testes Python, diagnóstico desktop e build TypeScript/Vite passaram no Windows. A evidência de instalação e interação da janela está em `docs/evidence/windows-release-0.4.1.json`.

Artefatos: `JevWIN_0.4.1_setup.exe`, `JevWIN_0.4.1_portable.zip` e `SHA256SUMS-0.4.1.txt`. SHA-256 do instalador: `b326d8d5cc2e92aae137f2ec9d0b7395d3dc60488035702ea9133612d2f4041d`.
